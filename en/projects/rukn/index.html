The story

Many Syrian merchants have products and customers, but online-selling tools are fragmented or costly. RUKN is one platform to launch and run a store at a fair price.

Every merchant sees only their data, every staff member only their permissions, and every order stays correct under concurrency — while staying simple for a first-time merchant.

The solution

A dashboard for orders, stock and payments, a visual editor with live preview, and a real storefront customers shop from.

  • Dashboard & publish status
  • Products & categories
  • Inventory & storage locations
  • Orders by stage
  • Abandoned carts
  • Payments via Sham Cash
  • Delivery & pickup
  • Visual store editor
  • Brand & themes
  • Analytics
  • Staff & permissions
  • Subscriptions & plans

Engineering

The backend is built on ASP.NET Core with Entity Framework Core over PostgreSQL; the interfaces use React and TypeScript; everything runs in Docker containers.

  • ASP.NET Core / .NET 10
  • React
  • TypeScript
  • PostgreSQL
  • Entity Framework Core
  • Docker
  • Cloudflare
  • Bunny
Tenant isolation
Store data is keyed to the tenant, and that constraint is enforced in the data-access layer rather than relying on each screen to remember it.
Authorization
Platform-admin permissions are separated from store-staff permissions, and every operation is authorized on the server.
Transaction safety
Linked operations — such as creating an order and reserving stock — run as one unit that either completes fully or not at all.
Concurrent operations
Handling two orders reaching for the same quantity at the same moment, so stock that no longer exists is never sold.
Data integrity
Database-level constraints keep relationships and states from reaching an invalid combination.

Key decisions

  1. One shared platform, not per-client copies

    A single codebase serving every merchant means maintenance and security fixes reach everyone at once, and keeps cost low.

  2. .NET and PostgreSQL for the core

    A mature, strongly typed stack with solid transactional support — because the product deals in money and stock.

  3. A long free trial

    Thirty days is enough to run the store and take real orders — more convincing than any sales pitch.
